# Corpus TOGAF incluido

Esta carpeta contiene el corpus autorizado que el Tutor TOGAF carga automáticamente
al iniciar. La aplicación extrae el texto, crea fragmentos con metadatos de página,
calcula embeddings localmente y prepara el índice Chroma. El estudiante no tiene que
cargar documentos ni crear el índice desde la interfaz.

Archivos localizados para este proyecto:

- `TOGAF_V9.1-Introduccion.pdf`
- `TOGAF_V9.1-FasePreliminar.pdf`
- `TOGAF_V9.1-VisionArquitectura.pdf`
- `TOGAF_V9.1-ArquitecturaNegocio.pdf`
- `TOGAF_V9.1-ArquitecturaInformacion.pdf`
- `TOGAF_V9.1-ArquitecturaAplicaciones.pdf`

Estos archivos se versionan junto al código por autorización del equipo del proyecto.
Al agregar documentos nuevos, confirma que el equipo tenga permiso para incluirlos en
el repositorio y despliegue públicos.
